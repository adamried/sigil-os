# Delegation contract

Sequential role adoption is the baseline. Delegate only a concrete, bounded,
independently verifiable item.

The payload must contain:

- resolved repository root;
- active phase and expected state revision;
- exact task and acceptance check;
- allowed file scope;
- role and specialist-overlay instructions;
- relevant constitution and active-waiver excerpts;
- required inputs and output schema.

The child never writes workflow state. The parent validates the result and
artifact before a transition. Parallel work is limited to independent reads,
research, reviews, or disjoint file scopes. Serialize any overlapping scope.

If delegation is unavailable, follow the same role reference sequentially and
produce the same artifact and handoff.
