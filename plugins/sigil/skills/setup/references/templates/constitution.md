# Project Constitution

> Status: Draft until reviewed with the project owner.

## Product and user outcomes

- Define the people served and the outcomes that matter.

## Technology constraints

- Record required languages, frameworks, data stores, and hosting constraints.

## Quality and testing

- Define the checks required before work is considered complete.

## Security and privacy

- Define access, data, credential, and compliance requirements.

## Simplicity and maintainability

- Prefer the smallest design that satisfies known requirements.

## Accessibility

- User interfaces meet WCAG 2.1 AA unless a stricter standard applies.
