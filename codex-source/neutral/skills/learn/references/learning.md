# Learning workflow

Capture only reusable, evidence-backed lessons. Each entry records date,
source feature/task, context, observation, recommended future action, and
confidence. Never store raw credentials. Run deterministic secret redaction;
review personal data on a best-effort basis.

Search and review load only relevant entries. Curation may merge duplicates
without deleting distinct evidence. Shared sync follows the adapter under
`../../draw/references/integrations/shared-context.md`.
