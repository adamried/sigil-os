# Status and resume procedure

Validate the state schema, then cross-check the recorded phase with the
required artifact and task status. If they disagree, explain the mismatch and
offer a dry-run repair; do not infer success.

Status reports:

- feature and track;
- completed/current/remaining outcomes;
- current blocker or next checkpoint;
- task counts;
- QA, code-review, security-report, and commit states separately;
- queued or failed optional remote outcomes.

Resume starts at the first incomplete valid phase, in a new session if durable
guidance or generated project agents changed.
