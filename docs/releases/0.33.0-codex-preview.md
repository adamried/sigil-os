0.33.0. It includes eight public skills, five workflow tracks, deterministic
project setup and state helpers, optional advisory hooks, optional project
agents, Jira and Figma apps, and a guarded GitHub shared-context adapter.

- deterministic build and checks 01–22;
- upstream Codex package validation;
- 29 deterministic test cases;
- all 68 model contracts parse, resolve their Codex sources, and pass dry run;
- a real Codex CLI 0.145.0 isolated marketplace/install/cache/setup run.

Model-based workflow scenarios, authenticated Jira/Figma test-resource runs,
and the full macOS/Linux release matrix remain release-checklist items. The
preview label cannot be removed until Core Parity is green on every claimed
surface.

Automatic commits default to off in the Codex edition. Hooks and custom agents
are optional. Core workflows continue when integrations are absent.

Printable guides still cover the Claude edition. Codex DOCX/PDF regeneration is
deliberately deferred until Core Parity passes on one claimed surface and the
eight-skill public surface is frozen.
